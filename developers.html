Choose your lab path

Node → node

Start with two machines on a trusted network. Pair them, test synthetic (made-up test) traffic in both directions and verify clean shutdown.

Node → your gateway → node

Evaluate a relay path using a reachable gateway on infrastructure you operate and pay for. This can help when direct connectivity is blocked by NAT (network address translation, which makes direct connections difficult).

Free lab software does not include Eigen-Systems-funded AWS (Amazon Web Services) resources or managed hosting. A gateway in your own cloud account is self-hosted. Eigen-Systems-operated infrastructure and engineering assistance require a paid scope.

Availability

Python tools are public now. macOS® Apple® Silicon/Intel and Linux® x86-64/ARM64 binaries (ready-to-run programs for these processor types) have been built; the lab distribution package and installation instructions are under review. Registration is not an immediate download. Windows support is not established.
