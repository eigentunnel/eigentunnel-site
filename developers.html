Corporate, government and academic emails are welcome. Independent consultants and researchers can request manual review. No payment card is required to request the free lab. Source access is a separate decision.

Availability

Python tools are public now. macOS Apple Silicon/Intel and Linux x86-64/ARM64 binaries have been built; the lab distribution package and installation instructions are under review. Registration is not an immediate download. Windows support is not established.

Relay connectivity has been founder-tested over macOS → AWS → macOS through Starlink NAT. Cloud payment and provisioning are unfinished. Algorithm implementation evidence and independent assessment status are separate from this connectivity test.
