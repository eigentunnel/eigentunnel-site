A migration bridge to evaluate

Test protection around a hard-to-change data path.

EigenTunnel is software for direct or relayed connections between enrolled systems. A scoped evaluation investigates whether connection-level protection can support a longer application or equipment migration.

Application source changes may be avoidable in suitable deployments; routing, firewall, node or gateway configuration can still be required. This is not a universal compatibility promise.

How the pieces fit

Establish keys

The private cnsa2 profile combines X25519 with ML-KEM-1024. ML-KEM establishes shared key material; it is not a bulk-data cipher. The combiner and complete protocol require independent review.

Authenticate peers

The private profile uses ML-DSA-87 signatures for identities. Production key lifecycle and revocation assurance remain separate review work.

Protect traffic

AES-256-GCM is the private profile’s bulk cipher. Encryption applies to configured paths, not unmanaged bypass traffic or a compromised endpoint.

Connect directly or via a gateway

Relay connectivity through Starlink NAT has been founder-tested. The relay trust boundary, metadata exposure and security properties must be verified for the deployed build.

The August binary packages predate September profile work. Do not assume the free evaluation package enables the private cnsa2 profile. Profile evidence and limits.

Where to start and where not to deploy

Good evaluation candidates include long-lived applications, vendor appliances, remote facilities and research links where a companion node or gateway can be installed. Use an approved lab environment with synthetic data.

Not offered for classified or life-safety operations, deployments requiring validated cryptographic modules or current CNSA/CSfC qualification, or systems where no companion component can be deployed. We do not claim anti-jamming, low probability of intercept/detection, disconnected operation or resilience against compromised endpoints.

Inventory and evidence are separate

CBOM discovery is a prototype. OSCAL SSP/POA&M/AP/AR are working drafts; the recorded v1.2.2 schema audit failed all four. Neither constitutes authorization. No tested GRC import or complete compliance automation is claimed.
