Install EigenTunnel leaf

Download the Mac leaf pack for a node that will run on macOS. Private keys are born on the Mac and never emailed.

Download macOS leaf pack Activate page

  1. Download and unzip eigen-leaf-macos.zip (folder: eigen-leaf-macos-bundle).
  2. Double-click Activate EigenTunnel.command.
  3. If macOS shows “Not Opened” (yellow warning): click Done (not Move to Trash) → System Settings → Privacy & Security → scroll down → Open Anyway → confirm Open.
  4. Paste your activate link (or token) when prompted. Accept the node name or type leaf-yourname.
  5. You should see {"accepted":true}.

Apple Silicon and Intel Macs are both in the zip. Needs Python 3 (preinstalled on macOS).

Use the installer for the OS where the node will run. This page is macOS only for now; Windows/Linux packs come later.

Do not email peer.env or any private key. Only the activate link/token is shareable.

Terminal unblock (if double-click stays blocked)

Paste this one line in Terminal, then press Return. Adjust the path if your unzip is not in Downloads:

xattr -cr ~/Downloads/eigen-leaf-macos-bundle && open ~/Downloads/eigen-leaf-macos-bundle/Activate\ EigenTunnel.command
Manual Terminal steps (same result) 
cd ~/Downloads/eigen-leaf-macos-bundle
chmod +x activate-and-register.sh leaf-pack/install.sh
./activate-and-register.sh 'PASTE_TOKEN_HERE' leaf-yourname
