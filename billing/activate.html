      Leaf install docs

    

      
This page is not the installer. It only shows your seat activate token. The node private key is created on your Mac and never uploaded.

      
On a Mac with the EigenTunnel leaf pack:

      
cd ~/EigenTunnel/leaf-pack
./activate-and-register.sh PASTE_TOKEN_HERE leaf-$USER

      
Or manually: run ./install.sh --no-wait in the leaf pack, copy EIGEN_PUBLIC_KEY_B64 from 01-SEND-THIS-FILE/peer.env, then:

      
export EIGENTUNNEL_RENDEZVOUS_URL=https://66rkpxcki4.execute-api.us-east-2.amazonaws.com/dev
export EIGENTUNNEL_ACTIVATE_TOKEN='PASTE_TOKEN_HERE'
export EIGENTUNNEL_TENANT_ID=field-test
export EIGENTUNNEL_NODE_ID=leaf-patrick-1
export EIGENTUNNEL_PEER_ID=leaf-patrick-1
export EIGENTUNNEL_DEVICE_PUBLIC_KEY='PASTE_PUBLIC_KEY_B64'
python3 leaf/install/register-public-peer.py

      
Do not email peer.env or any private key. Only the activate link / token is shareable.
