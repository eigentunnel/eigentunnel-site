# EigenTunnel site

Public marketing site for **EigenTunnel**, the hybrid post-quantum overlay previously marketed as FreeQ at [getfreeq.com](https://getfreeq.com).

Live GitHub Pages URL after Pages is enabled:

- `https://freeq-io.github.io/eigentunnel-site/`

## What this is

A static recreation of the getfreeq.com structure and claims, rebranded:

- FreeQ \u2192 EigenTunnel
- FQ mark \u2192 ET
- FreeQ Core / FreeQ Cloud \u2192 EigenTunnel Core / EigenTunnel Cloud
- Contact: patrick@eigen-systems.com
- Org: [github.com/freeq-io](https://github.com/freeq-io) (org display name is already EigenTunnel)

This is **not** Chad Fowler’s [freeq.at](https://freeq.at) IRC / AT Protocol product. Different product, same crowded name. That is why the overlay rebranded.

## Enable GitHub Pages

1. Open https://github.com/freeq-io/eigentunnel-site/settings/pages
2. Source: **Deploy from a branch**
3. Branch: `main` / root (`/`)
4. Save
5. Optional custom domain: add a `CNAME` file and point DNS

Suggested domains if getfreeq.com is retired:

- `eigentunnel.com` / `www.eigentunnel.com`
- `geteigentunnel.com`
- keep `getfreeq.com` as a redirect for a while

## Local preview

Open `index.html` in a browser. No build step.
