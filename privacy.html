Privacy notice (draft).

This page describes how the forms on this static site handle personal information today. It is a draft for counsel. It is not Eigen Systems' privacy policy.

What this draft describes

eigentunnel.com is static HTML. The contact page and the EigenScan page include forms so Eigen Systems can respond to a request. The EigenScan form is a request for an evaluation or a quote. It does not place an order.

Information the forms collect

Contact form: name, work email, company, what the person is interested in, and a message.

EigenScan request form: name, work email, organization, role, sector, approximate network segments or sites to scan, timeframe, whether the request is for an evaluation or a quote, and a message.

Both forms include a hidden field meant to catch automated spam. When that field is filled in, the intake script discards the submission and does not store it.

Where a submission goes

Each form posts to a Google Apps Script web app in the eigentunnel.com Google Workspace. The script adds a row to a Google Sheet named Leads and emails the submission to patrick@eigentunnel.com. Google keeps that sheet and that mailbox as part of the Workspace account. The site does not send form contents to a separate form vendor.

Intended use, which counsel still needs to confirm: read the request, reply to it, and keep a record of it.
