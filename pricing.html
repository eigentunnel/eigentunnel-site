Access and licensing

Public lab access is not the same as private Core access.

EigenTunnel is moving to an access model that supports testing and trust while preserving the proprietary functions that make the product sellable.

Public review

Core Public

Lab / inspection path

Minimal source, sanitized fixtures, and test recipes for security reviewers, developers, and test labs.

  • Buildable public lab kernel
  • Synthetic test recipes only
  • No scanner, Cloud, relay, installer, or customer workflow logic
  • Publication and license terms may change before general release

Commercial

Private Core and Cloud

Scoped / pilot or license

Access to commercial functionality is granted under private terms, NDA, pilot agreement, OEM license, or service contract.

  • Private Core capabilities and product-grade packaging
  • Cloud enrollment, evidence, integration, and workflow services
  • OEM and integrator licensing paths
  • Support, delivery, and deployment scope defined in writing

Questions

Access FAQ

Can a lab test EigenTunnel without private source?

Yes. Core Public is intended to provide a narrow, repeatable test surface with sanitized fixtures and no commercial workflow logic.

How do developers get private Core features?

Through an approved private access path: NDA, contributor agreement, pilot scope, OEM agreement, or partner delivery contract.

Can OEMs embed EigenTunnel?

Yes, but not by copying the public lab kernel and assuming product rights. OEM embedding needs a commercial license and support boundary.
